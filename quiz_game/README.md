# Quiz Game

A command-line multiple-choice quiz written in C++11. The game asks randomly
selected questions, applies a time limit, calculates a grade, and maintains a
separate leaderboard for each category. Each completed quiz is also appended
to a CSV history file for later analysis.

## Requirements

- A C++ compiler with C++11 support, such as GCC (`g++`)
- Windows for the live, no-Enter countdown input

On macOS and Linux, the game uses a portable fallback that accepts an answer
followed by Enter.

## Build and run

### Windows

The executable and Windows batch script are excluded from the email attachment.
Open PowerShell in the `quiz_game` directory and compile/run directly:

```powershell
mkdir data -ErrorAction SilentlyContinue
g++ -Wall -std=c++11 main.cpp quiz_core.cpp ranking.cpp categories.cpp random_questions.cpp timer.cpp scoring.cpp quiz_history.cpp -o quiz.exe
.\quiz.exe
```

### macOS or Linux

Run:

```sh
chmod +x build.sh
./build.sh
```

The commands above or the Unix script build and start the game. Ensure the `data/` directory exists.

## Project structure

- `main.cpp`: program entry point and main game flow
- `quiz.h`: shared settings and function declarations
- `quiz_core.cpp`: question loop and answer checking
- `categories.cpp`: categories, questions, choices, and correct answers
- `random_questions.cpp`: unique random question selection
- `timer.cpp`: timed answer input
- `scoring.cpp`: percentage, grade, and result summary
- `ranking.cpp`: per-category leaderboard storage and display
- `quiz_history.cpp`: elapsed-session CSV export
- `tests/`: standalone test programs for individual modules
- `data/`: generated leaderboard and quiz-history files

## Run individual tests

Compile each test with the module it tests. For example, on Windows:

```bat
g++ -Wall -std=c++11 tests/test_categories.cpp categories.cpp -o test_categories.exe
g++ -Wall -std=c++11 tests/test_random.cpp random_questions.cpp -o test_random.exe
g++ -Wall -std=c++11 tests/test_scoring.cpp scoring.cpp -o test_scoring.exe
g++ -Wall -std=c++11 tests/test_timer.cpp timer.cpp -o test_timer.exe
```

Run the resulting executable for the test you want to perform. The timer test
is interactive.

## Saved data

Leaderboards are stored as `data/leaderboard_category_<number>.txt`. These
files are generated by the game and intentionally excluded from Git.

Completed sessions are appended to `data/quiz_history.csv`. The file is
created automatically with this header:

```text
timestamp,username,category,correct_answers,total_questions,percentage,grade,duration_seconds
```

The timestamp uses local time, duration is recorded in seconds to three
decimal places, and text fields use standard CSV escaping. Existing records
are preserved, so the file can be loaded directly by CSV tools such as pandas.
